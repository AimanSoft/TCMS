# الكيانات الرئيسية للبيانات

## System Data Entities

## المقدمة
قائمة الكيانات الرئيسية للبيانات على مستوى عالٍ، مستخرجة من التحليل الأولي للمشروع. كل كيان يمثل جهة بيانات أساسية في النظام.

---

## 1. كيانات الهوية (Identity)

| الكيان | الوصف |
|---|---|
| Users | مستخدمي النظام |
| Roles | الأدوار المختلفة للمستخدمين |
| Permissions | الصلاحيات المرتبطة بكل دور |
| User_Roles | ربط المستخدمين بالأدوار |
| Role_Permissions | ربط الأدوار بالصلاحيات |

## العلاقات الأساسية بين الكيانات

```
Customer |—< Phone_Number |—< SIM |—< Subscription |—< Package
```

### شرح العلاقة:
- **Customer** يملك واحد أو أكثر من **Phone_Number**
- **Phone_Number** مرتبط بـ **SIM**
- **SIM** مرتبط بـ **Subscription**
- **Subscription** مرتبط بـ **Package**
