# الحدود الأولية للمشروع

## Project Boundaries

## المقدمة
تحدد هذه الوثيقة الحدود الأولية لمشروع نظام إدارة شركات الاتصالات، مستخرجة من التحليل الأولي للمشروع. تتضمن الحدود التشغيلية والوظيفية والتقنية.

---

## الحدود التشغيلية (Operational Boundaries)

- النظام هو **محاكاة إدارية** لشركة اتصالات فقط.
- النظام **لا يتصل بشبكات اتصالات حقيقية**.
- النظام **لا يتصل ببوابات دفع حقيقية**.
- النظام **لا يتصل بأبراج اتصالات حقيقية**.
- جميع الخدمات الخارجية هي **Simulated Services / Mock**.
- لا يتم التعامل مع أموال حقيقية أو بيانات عملاء حقيقية.
- جميع البيانات والعمليات داخل النظام هي بيانات وهمية (Mock Data).

---

## الحدود الوظيفية (Functional Boundaries)

### داخل النطاق (In Scope)
- إدارة العملاء
- إدارة الشرائح (SIM)
- إدارة الأرقام
- إدارة الباقات
- إدارة الاشتراكات
- إدارة الاستخدام
- إدارة الفواتير
- إدارة المدفوعات
- إدارة الشبكة والأبراج
- إدارة الأعطال
- إدارة الدعم الفني
- إدارة الإشعارات
- التقارير والإحصائيات
- صلاحيات المستخدمين (RBAC)

### خارج النطاق (Out of Scope)
- أي تكامل حقيقي مع شبكات اتصالات فعلية
- أي بوابات دفع حقيقية
- أي أبراج اتصالات حقيقية
- أي أجهزة شبكة حقيقية
- أي خدمات اتصال صوتي أو بيانات فعلية
- أي أنظمة خارجية حقيقية

---

## الحدود التقنية (Technical Boundaries)

- النظام يعتمد على **Microservices + API Gateway + Event-Driven Architecture**.
- هذا التوثيق يقتصر على المستوى الأولي فقط.
- لا تبدأ أي تفاصيل معمارية أو تصميمية في هذه المرحلة.
- تُوثق الحدود التقنية فقط على المستوى الأولي.
- التفاصيل المعمارية والتصميمية ستُحدد في المراحل اللاحقة.
