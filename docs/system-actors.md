# أصحاب العلاقة (Actors) في النظام

## System Actors

## المقدمة
قائمة أصحاب العلاقة الرئيسيين في نظام إدارة شركات الاتصالات، مستخرجة من التحليل الأولي للمشروع. لكل actor صلاحيات ومهام محددة ضمن النظام.

## قائمة الجهات الفاعلة (Actors)

> **ملاحظة:** جميع الجهات الفاعلة مصنفة إلى:
> - **داخلية (Internal):** Super Admin, Company Admin, Branch Manager, Customer Service Employee, Accountant, Network Engineer, Support Agent
> - **خارجية (External):** Customer

### 1. Super Admin
- **الوصف:** المشرف العام على النظام بكامل صلاحياته.
- **الصلاحيات:** كامل الصلاحيات على النظام بالكامل.
- **المسؤوليات:** إدارة النظام بشكل شامل، الإشراف على جميع الفروع والمستخدمين، التحكم في الإعدادات العامة.

### 2. Company Admin
- **الوصف:** مسؤول الشركة.
- **الصلاحيات:** إدارة الشركة، الفروع، الموظفين.
- **المسؤوليات:** إضافة الفروع، إدارة الموظفين، الإشراف على العمليات الإدارية للشركة.

### 3. Branch Manager
- **الوصف:** مدير الفرع.
- **الصلاحيات:** إدارة عمليات الفرع.
- **المسؤوليات:** متابعة عمليات الفرع، إدارة الموظفين داخل الفرع، الإشراف على الأنشطة اليومية.

### 4. Customer Service Employee
- **الوصف:** موظف خدمة العملاء.
- **الصلاحيات:** إدارة العملاء، الأرقام، SIM، الاشتراكات.
- **المسؤوليات:** تسجيل العملاء، إدارة أرقام الهواتف وشرائح SIM، معالجة الاشتراكات.

### 5. Accountant
- **الوصف:** المحاسب.
- **الصلاحيات:** الفواتير، المدفوعات، التقارير المالية.
- **المسؤوليات:** إصدار الفواتير، متابعة المدفوعات، إعداد التقارير المالية.

### 6. Network Engineer
- **الوصف:** مهندس الشبكة.
- **الصلاحيات:** الأبراج، المحطات، الأجهزة، الأعطال.
- **المسؤوليات:** إدارة الأبراج والمحطات، متابعة الأجهزة، تسجيل ومتابعة الأعطال التقنية.

### 7. Support Agent
- **الوصف:** موظف الدعم الفني.
- **الصلاحيات:** الشكاوى، التذاكر، متابعة المشاكل.
- **المسؤوليات:** استقبال شكاوى العملاء، إدارة التذاكر، متابعة حل المشاكل التقنية.

### 8. Customer
- **الوصف:** العميل / المشترك.
- **الصلاحيات:** عرض بياناته، أرقامه، باقته، استهلاكه، فواتيره، الدفع، فتح شكوى.
- **المسؤوليات:** عرض بيانات الاشتراك والاستهلاك، الدفع، فتح شكاوى عند الحاجة.
